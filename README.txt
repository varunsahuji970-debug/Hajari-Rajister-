SAHU CONSTRUCTION HAJIRI REGISTER

INSTALL / PUBLISH
1. Extract this ZIP.
2. Upload all four files/folder contents to the root of your GitHub Pages repository.
3. Wait for GitHub Pages to publish, then open the HTTPS site in Chrome on Android.
4. Chrome menu (three dots) > Add to Home screen / Install app.

FEATURES
- Add, edit and delete/archive sites; site name, party, location, phone.
- Add/edit/archive workers with daily wage rate.
- Separate Monday-Sunday register per site and week.
- Colour attendance buttons: P green, A red, H amber; tap again to clear.
- Automatic days, wage, advance and remaining balance.
- Paid checkbox per worker per week.
- Old weeks remain saved; CSV/Excel-compatible download and print-to-PDF.
- JSON backup and restore; offline PWA cache.

IMPORTANT DATA NOTES
- Data is stored locally in the browser on this device. It does not automatically sync to another phone.
- Download a JSON backup regularly, especially before clearing browser data or changing devices.
- A site with weekly records is archived instead of permanently deleted so old records remain safe.
- PDF button opens the Android/Chrome print screen; choose Save as PDF.
- CSV opens in Excel or Google Sheets.
